# FAQ2 Component Design Specification

**Date:** 2026-05-17  
**Status:** Approved  
**Scope:** New alternative FAQ component for service detail pages

---

## Overview

FAQ2 is a full-width, multi-column alternative to the existing `FAQs` component. It uses the site's raw three-column grid structure with visible side borders and is designed specifically for service detail pages (`/services/[slug]`).

---

## Purpose & Context

- **Where:** Bottom of every service detail page (`src/app/(frontend)/services/[slug]/page.tsx`), placed before the `CallToAction` component
- **What:** Display the same FAQ categories and items on all service pages (no per-service customization)
- **Design:** Follows the reference layout with full-width grid, visible borders, and responsive multi-column accordion layout

---

## Component Structure

### File Location
`src/components/faq-2.tsx`

### Component Type
Server component (no `'use client'` directive).

### Data Structure

Hardcoded FAQ groups (structured for future CMS integration):

```typescript
const faqGroups = [
  {
    title: string          // Category name (e.g., "General", "Services")
    items: [
      {
        value: string      // Unique ID for accordion item
        question: string   // FAQ question text
        answer: string     // FAQ answer text
      }
    ]
  }
]
```

**Initial data:** Use the same FAQ groups as the existing `FAQs` component (hardcoded).

## Layout Architecture

### Outer Grid (Three-Column Structure)

```
<div className="@container grid grid-cols-[auto_1fr_auto] lg:grid-cols-[1fr_auto_1fr] bg-border">
  <SideCol wide />           {/* Left border — responsive width */}
  <CenterContent />          {/* max-w-276 / lg:min-w-276 center column */}
  <SideCol />                {/* Right border — fixed narrow width */}
</div>
```

**Key:** 
- `bg-border` on the outer div makes the 0.5px gaps visible (reveals grid line color)
- Follows DESIGN.md "raw three-column structure" pattern (not `GridRow`)
- Proper spacing and padding to match the reference HTML

### Center Content Column

Max-width wrapper with responsive minimum width:
```
<div className="max-w-276 lg:min-w-276 mx-auto w-full">
  {/* Inner grid */}
</div>
```

### Inner Grid (Accordion Layout)

Multi-column responsive grid for accordion items:
- **Mobile:** 1 column
- **@2xl:** 2 columns (with left/right spacer columns hidden)
- **@4xl:** 4 columns (with 1-column spacers on left/right, 2-column accordion content in middle)

Structure:
```
<div className="**:data-grid-content:bg-card/90 **:data-grid-content:h-full **:data-grid-content:rounded grid *:p-[0.5px]">
  <div className="@2xl:grid-cols-[1fr_auto_1fr] @4xl:grid-cols-4 grid gap-px">
    {/* Spacer or content cells */}
  </div>
</div>
```

**Grid lines:** Made visible by:
1. `bg-border` on outer container
2. `*:p-[0.5px]` padding on cells (creates gaps)
3. `gap-px` between items
4. Each cell has `data-grid-content="true"` with `bg-card/90 h-full rounded`

---

## Sections

### 1. Heading Section
- **Location:** Top, full-width accordion row
- **Content:**
  - Title: "Frequently Asked Questions" (`text-4xl font-semibold`)
  - Description: "Discover quick and comprehensive answers..." (`text-lg text-muted-foreground`)
- **Layout:** Single `data-grid-content` cell, full width

### 2. Category Groups (Repeating)
For each category in `faqGroups`:
- **Category label:** `text-lg font-semibold text-foreground` (above accordion items)
- **Accordion items:** 
  - Uses existing `Accordion`, `AccordionItem`, `AccordionTrigger`, `AccordionContent` components
  - Each item: question as trigger, answer in content
  - Styling: Same as current FAQs for consistency

### 3. Support Section
- **Content:** "Can't find what you're looking for? Contact our [customer support team](link)"
- **Location:** Bottom of accordion grid
- **Styling:** `text-muted-foreground` body text, link is `text-primary font-medium`

---

## Responsive Behavior

| Breakpoint | Grid Columns | Visible | Notes |
|---|---|---|---|
| Mobile | 1 | Heading, all accordions | Single column, full content width |
| @2xl | 2 | Heading (full), accordion (2-col), support | Left/right spacers hidden |
| @4xl | 4 | All sections with spacer columns | 2 center columns for accordion, 1-col spacers on edges |

## Component Dependencies

- **UI Components:**
  - `SideCol` (from `@/components/ui/grid`)
  - `Accordion`, `AccordionItem`, `AccordionTrigger`, `AccordionContent` (from `@/components/ui/accordion`)
- **Utilities:**
  - `cn()` from `@/lib/utils` (if needed for conditional classes)

---

## Styling Guidelines

- **Background:** Inherits from parent layout; cells use `bg-card/90`
- **Typography:** 
  - Category labels: `text-lg font-semibold`
  - Accordion questions: Inherit from `AccordionTrigger` (same as FAQs)
  - Answers: Inherit from `AccordionContent`
  - Description text: `text-muted-foreground text-lg`
- **Spacing:** Matches reference HTML (6/12 padding on cells, 8px/space-y-8 between categories)
- **Borders:** Rely on `bg-border` + padding gap pattern from DESIGN.md
